# PForth

Interpretador e compilador Forth determinístico de 16 bits.

## Pré-requisitos

- **Make** — GNU Make 4.0+
- **GCC / Clang** — C++20 para o componente `cpp/`

## Instalação

```bash
make setup
make build
```

## Desenvolvimento

```bash
make build
make test
make quality
make clean
```
